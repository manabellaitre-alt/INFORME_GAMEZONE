Paneles privados y seguridad

Desarrollo de los paneles privados

Una vez implementadas las funciones principales, se completarán las páginas privadas de GAMEZONE.

Panel de usuario

Se desarrollará en inicio.php. Mostrará un mensaje de bienvenida, accesos a las diferentes secciones, videojuegos destacados y novedades.

Perfil

Se desarrollará en perfil.php y mostrará los datos personales de la cuenta.

Panel administrativo

Se desarrollará en admin_usuarios.php y permitirá gestionar los registros mediante el CRUD.

Para proteger estas páginas se utilizarán archivos de verificación de sesión y permisos.

El primer administrador se creará mediante un procedimiento controlado, con una contraseña procesada utilizando password_hash(). El formulario público de registro no permitirá que una persona se otorgue permisos administrativos.

Integración de los componentes

Cuando todos los archivos estén desarrollados, se conectarán entre sí para formar un único sistema. La integración permitirá que cada tecnología cumpla su función:

  • HTML organizará los contenidos.
  • CSS establecerá el diseño visual.
  • PHP procesará la información y ejecutará las funcionalidades.
  • PDO permitirá realizar consultas seguras.
  • MySQL almacenará los datos.
  • Las sesiones controlarán el acceso a las páginas privadas.

Se comprobará que los formularios envíen correctamente la información, que las consultas se realicen sobre la base de datos y que la navegación entre las diferentes páginas funcione como se espera.

Seguridad del sistema

Durante la programación se incorporarán medidas de seguridad para proteger las cuentas y la información almacenada.

  • password_hash() y password_verify(): para proteger las contraseñas.
  • Consultas preparadas mediante PDO: para reducir riesgos de inyección SQL.
  • Validación de los datos: recibidos en los formularios.
  • Control de sesiones: para proteger las páginas privadas.
  • Verificación de roles: para restringir las funciones administrativas.
  • htmlspecialchars(): para evitar que los datos ingresados se interpreten como código HTML.
  • Protección CSRF: en operaciones que modifiquen información.
  • Restricción de acceso: a las operaciones de edición, archivado y reactivación.

Estas medidas se aplicarán a medida que se desarrolle cada funcionalidad.
