01 · Introducción

Presentación del proyecto

GAMEZONE será una página web orientada al mundo de los videojuegos, pensada como un espacio digital para personas interesadas en el entretenimiento gamer.

La propuesta consiste en desarrollar una comunidad web que permita a sus usuarios registrarse, iniciar sesión y acceder a diferentes secciones con información relacionada con videojuegos, plataformas y novedades del sector.

El proyecto tendrá como característica principal un sistema de acceso obligatorio. Al ingresar a la página, los visitantes encontrarán inicialmente las opciones de registro e inicio de sesión. Una vez autenticados, podrán acceder al contenido privado de GAMEZONE.

Además de su temática, el objetivo central será desarrollar un sistema funcional de gestión de usuarios, aplicando conocimientos de programación web, conexión con bases de datos, formularios, sesiones y operaciones CRUD.

De esta manera, GAMEZONE no será solamente una página informativa, sino también un sistema funcional de gestión de usuarios.

Objetivos

Objetivo general

Desarrollar un sistema web funcional que permita registrar usuarios, autenticar sus cuentas y administrar la información almacenada en una base de datos, utilizando como temática una comunidad dedicada a los videojuegos.

Objetivos específicos

  • Diseñar una interfaz visual moderna, creativa y relacionada con el ambiente gamer.
  • Implementar formularios de registro e inicio de sesión.
  • Almacenar y consultar información mediante MySQL.
  • Incorporar sesiones para controlar el acceso.
  • Crear un panel personal para cada usuario.
  • Desarrollar un panel administrativo con operaciones CRUD.
  • Aplicar medidas de seguridad para proteger la información.
  • Realizar pruebas para comprobar el funcionamiento del sistema.
