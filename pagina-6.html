05 · Estructura del sistema

Archivos y base de datos

Creación y organización de los archivos

Desde Visual Studio Code se crearán las carpetas y los documentos que compondrán el proyecto. Se utilizará una estructura organizada para separar los archivos según sus responsabilidades.

Estructura prevista:

GAMEZONE/ │ ├── index.php ├── registro.php ├── login.php ├── inicio.php ├── juegos.php ├── perfil.php ├── cerrar_sesion.php │ ├── conexion.php ├── verificar_sesion.php ├── verificar_admin.php │ ├── admin_usuarios.php ├── registrar_usuario.php ├── editar_usuario.php ├── archivar_usuario.php ├── usuarios_archivados.php ├── reactivar_usuario.php │ ├── includes/ │ ├── header.php │ └── footer.php │ ├── css/ │ └── estilos.css │ ├── img/ │ ├── logo.png │ ├── portada.jpg │ ├── juego1.jpg │ ├── juego2.jpg │ └── juego3.jpg │ └── database/ └── gamezone_db.sql

Los nombres y las responsabilidades podrán ajustarse durante la programación, pero se mantendrá esta organización general.

Creación de los archivos HTML y PHP

Se utilizarán documentos con extensión .php para construir la mayoría de las páginas. Estos archivos permitirán combinar la estructura HTML con las instrucciones PHP necesarias para procesar información.

Por ejemplo, registro.php contendrá los elementos HTML del formulario y el código PHP que recibirá, validará y guardará los datos ingresados.

Las páginas se construirán mediante elementos como encabezados, títulos, párrafos, formularios, imágenes, botones, enlaces y secciones.

Creación del archivo CSS

Dentro de la carpeta css se creará estilos.css, que contendrá las reglas visuales del sitio. Se definirán los colores, tipografías, fondos, márgenes, tamaños, botones, formularios, tarjetas de videojuegos, tablas y distribución de los elementos.

El archivo se vinculará con las páginas PHP mediante una referencia dentro de la sección head del documento HTML.

De esta manera, se podrá mantener una identidad visual compartida y realizar modificaciones generales sin repetir los estilos en cada página.

Incorporación de imágenes

Se creará la carpeta img, donde se almacenarán el logo, las imágenes de portada, las portadas de videojuegos y los recursos decorativos.

Los archivos se organizarán con nombres identificables para facilitar su incorporación en las distintas secciones.

Archivos compartidos

También se podrán crear documentos complementarios, como header.php y footer.php para reutilizar el encabezado, la navegación y el pie de página. Esto permitirá mantener una estructura uniforme y evitar repetir el mismo código en todas las páginas.

Creación de la base de datos

Una vez preparada la estructura del proyecto, se procederá a configurar la base de datos.

Se ingresará a phpMyAdmin desde el navegador mediante:

http://localhost/phpmyadmin/

Allí se creará una base de datos denominada gamezone_db y, dentro de ella, una tabla principal llamada usuarios.

CampoFunción
idIdentificador único del usuario.
nombreNombre.
apellidoApellido.
dniDocumento de identidad.
emailCorreo electrónico.
passwordContraseña almacenada mediante hash.
rolIdentifica si es usuario o administrador.
estadoIndica si está activo o archivado.
fecha_creacionFecha de registro.
fecha_archivadoFecha de archivado, si corresponde.

Se establecerán restricciones para evitar que existan dos cuentas con el mismo DNI o correo electrónico.

También se configurará el identificador id como clave primaria, permitiendo localizar cada registro de manera individual.
