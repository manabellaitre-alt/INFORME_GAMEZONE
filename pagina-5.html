04 · Producción técnica

Planificación del desarrollo

Una vez definido el planteamiento de GAMEZONE, se comenzará con su construcción técnica. El desarrollo se realizará por etapas, utilizando herramientas específicas para programar, diseñar, ejecutar el sitio y administrar la información.

La producción comenzará con la preparación del entorno de trabajo, continuará con la creación de los archivos y la base de datos, y finalizará con la integración de las funcionalidades, las medidas de seguridad y las pruebas.

Herramientas y tecnologías

Visual Studio Code

Será el editor principal donde se crearán, organizarán y modificarán los archivos PHP, HTML y CSS.

XAMPP

Permitirá ejecutar el proyecto de manera local mediante Apache y MySQL.

PHP

Se encargará de procesar formularios, gestionar sesiones, verificar usuarios y ejecutar las operaciones del sistema.

MySQL

Será el sistema encargado de almacenar y administrar los datos de los usuarios.

phpMyAdmin

Permitirá crear y administrar visualmente la base de datos, sus tablas y registros.

HTML y CSS

HTML organizará la estructura de las páginas y CSS definirá su apariencia visual.

Preparación del entorno de desarrollo

El primer paso será instalar y configurar las herramientas necesarias. Se instalará XAMPP y se comprobará que los servicios Apache y MySQL puedan iniciarse correctamente desde su panel de control.

Luego, se instalará Visual Studio Code y se creará una carpeta denominada GAMEZONE dentro del directorio htdocs de XAMPP.

C:\xampp\htdocs\GAMEZONE

Esta carpeta contendrá todos los archivos necesarios para el funcionamiento del sitio.

Una vez iniciado el servidor, se podrá acceder al proyecto desde el navegador mediante LOCALHOST.
