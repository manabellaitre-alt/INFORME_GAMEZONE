Conexión, acceso y administración

Conexión entre PHP y MySQL

Después de crear la base de datos, se desarrollará el archivo conexion.php. Su función será establecer la comunicación entre PHP y MySQL utilizando PDO.

Esta conexión será utilizada por las diferentes páginas para guardar, consultar y modificar información.

Por ejemplo, cuando una persona se registre, PHP utilizará la conexión para insertar sus datos en la tabla usuarios. Cuando intente iniciar sesión, permitirá consultar si su cuenta existe y verificar sus credenciales.

La conexión se reutilizará mediante instrucciones como require o include, evitando escribirla nuevamente en cada archivo.

Programación del registro y el inicio de sesión

Registro

Se programará el formulario en registro.php, con los campos de nombre, apellido, DNI, correo electrónico y contraseña.

PHP comprobará que los campos estén completos, que los datos sean válidos y que no existan cuentas con el mismo DNI o correo.

Si la información es correcta, se almacenará en MySQL. La contraseña se procesará mediante password_hash() para evitar guardarla como texto sin protección.

Inicio de sesión

En login.php se desarrollará el formulario de acceso.

El sistema consultará la cuenta correspondiente y verificará la contraseña mediante password_verify().

Si los datos son correctos, PHP iniciará una sesión mediante session_start(), permitiendo reconocer al usuario durante su navegación.

Si los datos son incorrectos, se mostrará un mensaje de error.

Cierre de sesión

Se creará cerrar_sesion.php, encargado de finalizar la sesión y devolver al usuario a la pantalla de acceso.

Desarrollo del CRUD y administración de usuarios

Una vez que el registro y el inicio de sesión estén funcionando, se desarrollará el CRUD, una de las partes centrales del trabajo práctico.

CRUD representa cuatro operaciones fundamentales para administrar información:

CREATE

Crear registros.

READ

Consultar registros.

UPDATE

Actualizar registros.

DELETE

Eliminar registros.

En GAMEZONE se utilizará una eliminación lógica: en lugar de borrar definitivamente una cuenta, se archivará para conservar sus datos y permitir su reactivación.

OperaciónDesarrollo previsto
CREATE – Crear usuarios Se desarrollará un formulario administrativo para incorporar nuevas cuentas. Al enviar los datos, PHP los validará y los guardará en MySQL.
READ – Consultar usuarios En admin_usuarios.php se mostrará una tabla con los usuarios registrados. Se incorporará un buscador que permita localizar cuentas mediante nombre, apellido, DNI o correo electrónico.
UPDATE – Modificar usuarios Mediante editar_usuario.php, el administrador podrá seleccionar una cuenta, visualizar sus datos actuales y modificar la información permitida.
DELETE – Archivar usuarios Mediante archivar_usuario.php, se cambiará el estado de una cuenta a archivado, conservando su información en la base de datos.
Reactivación Se creará usuarios_archivados.php para consultar las cuentas archivadas y reactivar_usuario.php para permitir que vuelvan a estar activas.

Todas estas acciones estarán protegidas para que solamente un administrador autorizado pueda ejecutarlas.
